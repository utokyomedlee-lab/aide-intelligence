# Aide Intelligence — Privacy Notice (Public Preview)

Last updated: 2026-11-24

Aide Intelligence is an early public preview and is not an account-based service.

## Information handled

- The browser stores conversation history in local storage on the device and browser currently being used. It does not sync to other devices.
- When the AI API is configured, the recent messages needed to answer the current request are sent from this server to the OpenAI API.
- The Aide server does not intentionally save conversation transcripts in a server-side database.
- The server may temporarily process an IP address for basic in-memory rate limiting. The rate-limit counters are volatile and reset when the server restarts.

## Avoid entering sensitive data

Do not submit passwords, authentication codes, government identification numbers, bank/payment details, confidential client records, trade secrets, or sensitive health information.

## Third-party AI processing

When AI mode is enabled, submitted conversation text is processed by the configured OpenAI API service. Review the applicable OpenAI API data controls and terms before using this preview with personal or confidential information.

## Retention and deletion

Conversation history is stored in the browser's local storage. Clear this site's data or browser storage to delete the local history. This preview has no user account or server-side conversation database.

## Limitations

This notice is a prototype disclosure, not a substitute for a jurisdiction-specific legal review. Before broad public promotion or commercial use, have the final privacy policy, terms of service, retention controls, and consent flow reviewed by qualified counsel.

Contact: use the public GitHub repository's Issues page for non-sensitive project questions. Do not post private data or API keys there.
